Aula 3 de 14

Criar a pasta do seu mentor

Você consegue criar a pasta do seu mentor com dois comandos e conferir que nasceram o agente, as seis skills e o portão.

Montar um mentor do zero levaria dias: pastas, regras, conferências. O kit da comunidade INEMA faz esse esqueleto em segundos. Você só precisa colar dois comandos e saber o que olhar no resultado.

Em 1 minuto

  1. Primeiro comando: baixar o kit para o seu computador.
  2. Segundo comando: criar o mentor com nome, especialista e a frase de domínio.
  3. Confira três coisas: o agente, as seis skills e o portão.

1Confira as três ferramentas antes

Tudo nesta aula acontece no terminal. O kit precisa de três ferramentas no computador: Python, git e o Claude Code, que você já abriu antes.

Para abrir: no Windows, procure "PowerShell" no menu Iniciar; no Mac, procure "Terminal" no Spotlight; no Linux, aperte Ctrl+Alt+T. Abre uma janela com uma linha piscando. Ali você cola o comando e aperta Enter.

Marta abriu o terminal do notebook da escola e digitou os dois comandos abaixo. Cada um respondeu com um número de versão.

Se travou aqui, é normalNo Windows, "python3" às vezes não existe. Digite python --version e use "python" no lugar de "python3" em todos os comandos desta aula. Se aparecer "não reconhecido" ou "command not found", a ferramenta falta: baixe o Python em python.org e o git em git-scm.com, use as opções padrão, feche e abra o terminal de novo.

2Primeiro comando: baixar o kit

O kit fica num repositório público no GitHub. O comando abaixo baixa uma cópia dele para a sua pasta pessoal.

Rui colou o comando no terminal do escritório. Em poucos segundos apareceu a pasta mentor-especialista dentro da pasta dele.

3Segundo comando: criar o mentor

Agora entra o script novo-mentor.py. Ele pede um slug, o nome do especialista e a frase de domínio que você escreveu na aula 2.

Marta usou o slug helena e colou a frase de domínio que tinha guardado nas Notas. Veja a resposta real do kit.

4O que cada pasta guarda

Dentro de mentores/mentor-helena nasceu uma estrutura pronta. Você não precisa decorar. Basta saber onde mora cada parte.

A pasta .claude começa com ponto, por isso fica oculta no gerenciador de arquivos. As três peças que você vai conferir moram nela: o agente, as seis skills e o portão de execução, que é um hook.

Pratique agora 0/3

Crie o seu mentor e confira o que nasceu

Pronto quando o terminal listar o agente, as seis skills e o portão. Cerca de 10 minutos, no computador.

Tudo fica numa pasta nova só sua; nada é enviado a lugar nenhum. Se aparecer "já existe", escolha outro slug. Se aparecer "slug inválido", use só minúsculas, números e hífen.

git clone https://github.com/inematds/mentor-especialista.git ~/mentor-especialista

python3 ~/mentor-especialista/novo-mentor.py <slug> --nome "<nome do especialista>" --dominio "<sua frase de domínio>" --destino ~/mentores

cd ~/mentores/mentor-<slug>

ls .claude/agents .claude/skills .claude/hooks

Você criou o esqueleto do seu mentor e conferiu as três peças. Nas próximas aulas, sempre que pedirem para "entrar na pasta do mentor", é abrir o terminal e colar cd ~/mentores/mentor-<seu slug>.
