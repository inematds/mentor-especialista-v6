# Mentor-Especialista v6

Curso aberto (formato INEMA v6, aulas de uns 15 minutos): **uma IA que ensina do jeito de quem você admira**. Você monta no Claude Code um mentor que aprende só com o que um especialista publicou, mostra de onde tirou cada regra e só diz que funciona depois de rodar. O caso real é o mentor do Nei, com acertos e falhas.

- Curso: https://inematds.github.io/mentor-especialista-v6/
- Kit: https://github.com/inematds/mentor-especialista
- Piloto: https://github.com/inematds/mentor-nei
- Versão v2 (mais técnica): https://inematds.github.io/mentor-especialista-curso/

14 aulas em 4 módulos: Por que um mentor · Montar o acervo · Regras e mentor · Provar e manter.
